BUSCADOR DE LOJAS - SHOPPING D

ARQUIVOS:
- index.html = buscador principal
- admin.html = tela simples para adicionar e excluir lojas
- lojas.json = lista original de lojas
- argoplan-shoppingd.png = logos

COMO USAR:
1. Abra index.html.
2. Clique em "Gerenciar lojas".
3. Para adicionar: preencha Andar, LUC e Nome e clique em Adicionar.
4. Para excluir: pesquise a loja e clique em Excluir.
5. As alterações ficam salvas no navegador usado.
6. Para levar as alterações para outro computador, use "Exportar dados" e depois "Importar dados".

OBSERVAÇÃO:
Em site estático (GitHub Pages), alterações feitas pelo painel ficam salvas apenas no navegador/dispositivo.
Para um painel que altere a lista para todos os usuários automaticamente, será necessário um banco de dados/backend.
